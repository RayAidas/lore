# 质量要求与路线图

## 非功能需求

### 性能

- 普通编辑操作应保持即时响应。
- 大型书库搜索和索引不得阻塞编辑器。
- 长章节输入时避免全量重新解析和渲染。
- 桌面端和移动端均控制内存占用，按需加载未打开文档。

### 可靠性

- 文件写入尽量使用临时文件与原子替换，降低损坏风险。
- 元数据更新失败不得影响正文文件读取。
- 应用异常退出后可恢复最近编辑状态。
- 所有派生状态都应能够从真实文件或历史记录重建。

### 隐私与安全

- 默认不上传用户内容。
- 未来调用 AI 时明确标识数据将发送给第三方模型服务。
- API Key 不记录在日志中。
- 日志默认避免包含完整正文。

### 可访问性

- 支持系统字体缩放和高对比度需求。
- 关键操作支持键盘快捷键。
- 不仅依赖颜色表达保存、冲突和错误状态。

## 第一阶段目标

第一阶段需要验证三个核心体验：

1. 用户愿意长时间在 Lore 中写作。
2. 用户愿意将作品和相关资料放入书库。
3. 用户能够安全迁移、管理和导出已有作品。

## MVP 范围

### 包含

- 单书库及真实文件系统管理。
- 新建、导入和管理小说。
- 正文、卷、章结构及排序。
- 普通文件夹、TXT、Markdown 文件管理。
- 多标签页编辑。
- 自动保存与基础历史版本。
- TXT 和 Markdown 编辑、预览。
- 小说、正文和卷概览。
- 基础沉浸写作模式、主题和排版配置。
- 当前章、当前卷和整书阅读模式。
- 模板系统。
- 全文搜索。
- 回收站。
- 小说合并导出为 TXT、Markdown。
- macOS 优先实现，并完成 Android 核心写作与阅读适配。

### 暂不包含

- AI Agent。
- 官方云同步。
- 多人实时协作。
- 社区、作品发布和网文平台直传。
- 完整插件系统。
- Canvas、白板和复杂知识图谱。
- 多 Agent 编排。
- Windows、Linux 和 iOS 的深度适配。
- 复杂 Markdown 所见即所得编辑器。

## 建议开发顺序

1. 建立 Flutter 工程与跨平台基础架构。
2. 实现书库、文件系统访问和元数据模型。
3. 实现小说、正文、卷、章的创建与管理。
4. 实现 TXT、Markdown 编辑器和多标签页。
5. 实现自动保存、历史版本和异常恢复。
6. 实现小说、正文和卷概览。
7. 实现沉浸写作、主题与排版设置。
8. 实现章节、卷和整书阅读模式。
9. 实现模板、全文搜索和回收站。
10. 实现导入、导出和迁移工具。
11. 完成 Android 输入、后台保存和阅读适配。
12. 基础体验稳定后设计并实现 AI Agent。

## 实现进度（2026-07-23，`main`）

P0 核心写作闭环已合入 `main`，并在其上持续补齐以下能力：

- 设置页：主题（素白 / 纸张 / 霜华 / 翠微 / 夜间 / 墨渊）、默认章节格式、编辑器排版（字号、行高、行宽）、每日字数目标。
- 查找替换：Cmd+F / Cmd+G / Cmd+Shift+G / Cmd+H，区分大小写、正则、`$1`-`$9` 捕获组。
- 小说概览页：总字数、章节数、卷数、今日字数、目标进度、卷摘要、封面。
- 删除与回收站：移入 `.lore/trash/`、清单、崩溃恢复、孤儿对账、恢复冲突策略（覆盖 / 跳过 / 重命名）、永久删除二次确认。
- 长文编辑优化（macOS）：TXT 使用分块文本 buffer 和可视区域虚拟化，支持增量统计、跨块事务撤销、IME composing 保护和异步查找。
- Android SAF：目录授权持久化、扫描、创建、编辑、重命名、移动、回收站与冲突保存；回到前台后自动重扫。
- 沉浸写作：打字机模式、专注模式，可配置排版、背景图与写作目标。
- 历史版本：切换 / 关闭 checkpoint 与变更量阈值自动留档、sha256 去重、分层时间窗保留、版本 diff 与恢复。
- 写作统计：今日 / 本周净增、连续写作天数、当月日历回顾（书库级与小说级，按本地自然日）。
- 导入导出：导入单个 TXT 文件（含编码探测），小说或卷按阅读顺序合并导出为 TXT。
- 小说内章节搜索：跨章节正文匹配并跳转命中位置。

后续待办（参考上方 MVP 清单）：

- 阅读模式（章 / 卷 / 整书连续）。
- 全书库索引搜索（小说内章节搜索已落地，跨书库的 SQLite 全文索引待实现）。
- 模板系统。
- Android 真机输入法适配、视口锚点恢复与沉浸式排版（SAF 存储链路已完成）。
- AI Agent（待基础写作与阅读稳定后启动）。

## 后续待细化事项

- Android 不同 SAF 文档提供者的兼容性和降级策略。
- 文件在外部同时移动并修改时的身份恢复准确性。
- 章节批注在正文修改后的锚点算法。
- Markdown 编辑器组件和增量解析方案。
- 搜索索引技术选型及中文分词策略。
- 模板实例化时的命名冲突和变量输入交互。
- 导入大 TXT 时的章节标题识别规则。
- 未来跨端同步的协议与冲突解决界面。
- 正式视觉语言、品牌名称、图标和主题规范。
