# AI Agent 设计

> 实施阶段：后续版本

AI 不进入早期核心版本，待基础写作、阅读和书库能力稳定后实现。右侧工具栏和底层命令体系可提前保留扩展点，但不应拖慢首版开发。

## 启用方式

- 用户填写自己的 API Key 后才能启用 AI。
- API Key 存储于 macOS Keychain 或 Android Keystore，不写入书库和普通配置文件。
  > 偏离记录（2026-08-04）：当前实现按产品要求把 API Key 与配置一并**明文**存于
  > 应用内 SharedPreferences，未使用系统安全存储。这是有意取舍（简化跨平台与离线
  > 可用、避免 macOS 无签名环境的 keychain entitlement 限制），设置页已向用户提示
  > 明文存储风险。后续如需恢复 Keychain/Keystore，需配置 macOS 开发签名并加回
  > `keychain-access-groups`（非空值）entitlement。
- 模型接口保持抽象，优先兼容通用的 OpenAI 风格接口，并允许后续接入其他服务。
- 不在日志、崩溃报告或导出的书库数据中记录 API Key。

## 展现方式

- 桌面端以可展开、收起的右侧栏对话形式展示。
- 移动端使用独立工具页面或底部面板，不持续挤压正文编辑区域。
- 对话中应明确显示当前上下文范围和即将执行的工具操作。

## 上下文范围

- 当前选中文字。
- 当前文档。
- 当前卷。
- 当前小说。
- 整个书库。

默认从最小必要范围开始。扩大读取范围时，应让用户清楚知道 AI 将访问哪些内容。

长篇作品不能在每次对话中发送全文。后续需要使用章节摘要、搜索索引和按需读取工具构建上下文。

## 初期能力

- 检查错别字、病句和标点。
- 润色或改写选中文字。
- 总结章节和生成章节摘要。
- 提取人物、地点和事件。
- 检查人物名称、设定和前后文矛盾。
- 搜索书库资料并回答问题。

## 大纲生成

AI 可按提示生成完整大纲，并按分类自动保存到小说的对应目录。

### 输入

面板中按提示填写：主题/书名（必填）、世界背景、人物设定、卷设定、章设定、补充要求。
已关联的大纲（`NovelOutlineLinks`）作为参考材料前置传入，仅作设定与风格参考。

### 生成方式（分步）

1. 第 1 步：生成「世界观 + 人物设定」，要求严格输出 `# 世界观`、`# 人物设定` 两个一级章节。
2. 第 2 步：把第 1 步结果作为参考，生成「卷章大纲」，要求严格输出 `# 卷章大纲`，
   下挂 `## 第X卷`、`### 第X章`，每章仅一句话概括核心情节（压缩篇幅、防截断）。

两步均使用较长超时（默认 180s）。第 1 步输出按一级标题解析，识别「世界观/世界背景/
世界设定」「人物设定/人物/角色设定」别名；两个标题都未命中时把全文作为世界观兜底保存，
避免内容丢失。

### 自动分类保存

```text
小说/
├── 大纲/大纲-<主题>.md        ← 卷章大纲（自动打开并关联到「关联大纲」）
├── 世界观/<主题>-世界观.md
└── 人物/<主题>-人物.md
```

分类文件为空时跳过对应文件；命名主干跨三个目录统一去重（冲突追加 `-2`、`-3`…）。
大纲文件位于 `大纲/` 兄弟目录、不参与内容树（与手动「新建大纲」一致）。

### 范围与限制

- 本期只生成大纲文档，不在 `正文/` 下创建卷/章结构。
- 世界观/人物文件不进入 `NovelOutlineLinks`（该模型只跟踪 `大纲/` 下的文件）。
- 长篇小说大纲仍受单次输出长度与模型能力约束，分步生成已降低整体截断风险。

## Agent 工具方向

初期可以围绕以下能力设计受控工具：

```text
read_file
search_files
list_directory
get_novel_structure
get_document_outline
create_file
apply_patch
move_file
add_comment
update_metadata
```

工具名称和参数属于实施细节，正式开发时另行定义接口协议。

## 操作边界

- 读取操作可以在用户授权范围内执行。
- 创建、修改、移动和删除操作必须预览并确认。
- 文本修改必须展示差异，支持逐处接受或拒绝。
- AI 修改前自动创建历史快照。
- 保存 Agent 操作日志并提供撤销入口。
- 用户可以限制 AI 访问指定目录或文件。
- 多 Agent 和复杂工具编排属于更后期能力。

## 隐私要求

- 默认不上传用户内容。
- 调用 AI 时明确标识数据将发送给第三方模型服务。
- 日志默认避免包含完整正文。
- 用户删除 AI 对话时，应同时清理本地保存的相关上下文数据。
