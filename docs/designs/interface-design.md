# 界面与交互设计

## 桌面端布局

macOS 端优先采用可收起的三栏布局，并保留全局功能导航和底部状态栏。

```text
┌──────┬──────────┬────────────────────────┬──────────────┐
│功能栏│ 文件树    │ 标签页 / 内容区域       │ 右侧工具栏    │
│      │          │                        │ AI / 属性等   │
├──────┴──────────┴────────────────────────┴──────────────┤
│ 字数、保存状态、光标位置、写作目标、同步状态             │
└─────────────────────────────────────────────────────────┘
```

### 左侧功能栏

- 文件。
- 搜索。
- 小说项目。
- 最近打开。
- 收藏。
- 模板。
- 回收站。

知识图谱等高级能力不进入第一阶段。

### 文件树

- 展示书库的真实文件夹和文件结构。
- 在显眼位置提供“新建小说”入口。
- 小说、正文、卷、章使用不同但统一风格的图标。
- TXT 和 Markdown 使用可区分的文件图标。
- 模板对象显示模板标识。
- 支持展开、收起、拖动、重命名、复制、移动和删除。
- 根据当前节点提供具有上下文的创建菜单。

书库根节点的创建菜单包括：

- 新建小说。
- 新建普通文件夹。
- 新建 Markdown 文件。
- 新建纯文本文件。
- 从模板创建。
- 导入文件或文件夹。

小说节点优先提供新建卷、章节、普通文件夹、普通文件和从模板创建。卷节点优先提供新建章节、普通文件夹、普通文件和从模板创建。

### 中间内容区域

- 支持多标签页同时打开多个对象。
- 点击小说显示小说概览。
- 点击正文显示正文结构和阅读顺序。
- 点击卷显示卷概览。
- 点击文件显示编辑或阅读内容。
- 标签页支持固定、关闭其他、关闭右侧和恢复最近关闭。

### 右侧工具栏

第一阶段可包含：

- 当前文档属性。
- 文档大纲。
- 写作统计。
- 批注与问题标记。
- 历史版本。

后续加入反向链接、AI Agent 和小说级分析工具。左右侧栏均可独立收起，沉浸模式下默认隐藏非必要区域。

## 移动端布局

Android 端不直接缩小桌面三栏布局，采用内容优先的单页结构：

- 首页展示最近小说、最近文档和写作统计。
- 编辑页优先全屏显示正文。
- 通过抽屉或页面切换访问文件树。
- 通过独立工具入口访问文档属性、历史和后续 AI。
- 底部工具栏保留撤销、重做、搜索、格式和阅读模式等高频功能。
- 阅读模式采用小说阅读器的点击、滑动和沉浸交互。
- 平板和折叠屏可根据宽度切换为双栏布局。

Android 端重点保证：

- 输入法弹出后光标和当前行可见。
- 返回键行为可预测，不误退出或丢失内容。
- 应用切入后台前可靠保存。
- 大文档滚动和输入流畅。
- 编辑手势、系统返回手势和阅读翻页手势不冲突。

## 概览页面

### 小说概览

- 书名、封面和简介。
- 当前字数、章节数和卷数。
- 最近编辑章节。
- 今日、本周写作字数。
- 写作目标和完成进度。
- 卷章结构摘要。
- 继续写作、从头阅读和导出小说入口。

### 正文概览

- 按作品顺序混合展示卷和直属章节。
- 支持拖动排序。
- 支持新建卷和新建章节。
- 支持连续阅读全部正文。
- 支持检查未编号、重复编号和缺失文件。

### 卷概览

- 卷名和可选简介。
- 章节数量和总字数。
- 章节列表及排序。
- 最近编辑位置。
- 新建章节和连续阅读本卷入口。
