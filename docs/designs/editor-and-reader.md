# 编辑与阅读设计

## 文件格式

- 完整支持 `.txt` 纯文本文件。
- 完整支持 `.md` Markdown 文件。
- TXT 和 Markdown 均支持编辑、搜索、字数统计、历史版本和阅读模式。
- TXT 阅读排版只改变展示效果，不向原文件写入排版标记。
- Markdown 第一阶段采用源码编辑、轻量语法高亮和独立预览，不优先实现复杂所见即所得编辑。

## 基础编辑能力

- 撤销和重做。
- 查找与替换。
- 自动保存。
- 多标签页。
- 基础 Markdown 快捷输入。
- 中文标点与全角、半角辅助。
- 当前文件和选中文字数统计。
- 打开时恢复光标和滚动位置。
- 支持超长章节，避免因全文重建导致输入卡顿。

## 编辑与预览模式

- TXT 文件提供纯文本编辑和小说排版阅读两种主要视图。
- Markdown 文件提供源码编辑、渲染预览和编辑预览分屏。
- 编辑排版设置与磁盘内容解耦，字体、缩进和段距变化不应无意改写原文件。
- 阅读和预览应正确处理 Markdown 标题、引用、列表、强调、链接、图片和代码块等基础语法。

## 沉浸式写作

- 无干扰全屏模式。
- 打字机模式，使当前行保持在屏幕相对固定位置。
- 专注模式，弱化非当前段落或句子。
- 可配置正文行宽、页边距、首行缩进、段间距和行高。
- 可配置字体、字号、字重和光标样式。
- 支持应用主题和编辑器主题分别设置。
- 支持背景颜色、图片或轻量纹理。
- 支持可关闭、可调节音量的打字音效。
- 支持写作目标、计时和基础写作统计。

首批主题应少而精，重点验证长时间写作和阅读的舒适度，例如素白、纸张、翠微和夜间主题。

## 阅读体验

阅读模式不只是禁用编辑，而应接近小说阅读器。

### 阅读范围

- 当前章节。
- 当前卷连续阅读。
- 整本小说连续阅读。

### 阅读方式

- 上下连续滚动。
- 左右滑动翻页。
- 点击屏幕区域翻页。
- 显示阅读进度和章节跳转。
- 记住每部小说和每个文件的阅读位置。
- 支持从阅读位置快速返回编辑位置。

### 阅读设置

- 字体和字号。
- 行距、段距和页边距。
- 日间、夜间和翠微主题。
- 滚动或翻页动画。
- 界面自动隐藏。

## 审稿交互

- 阅读时选中文字添加批注或问题标记。
- 退出阅读后集中查看并逐条处理。
- 批注不直接污染 TXT、Markdown 正文。
- 修改正文后能够识别已经失效的批注位置。
